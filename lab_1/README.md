# Лабораторная работа №1

**Вариант:** 9  

## Задание

Реализовать взаимодействие родительского и дочернего процессов с использованием неименованного канала `pipe`.

Родительский процесс открывает входной файл и запускает дочернюю программу. Дочерний процесс выполняет последовательное деление первого числа каждой строки на остальные и передаёт результат родителю через канал. При делении на ноль выполнение прекращается.

## Компиляция и запуск

**Поддерживаемая среда:** Linux (в том числе Ubuntu через WSL)

Для компиляции используются команды:

```bash
gcc parent.c -o parent
gcc child.c -o child
```

Запуск программы:

```bash
./parent
```

После запуска необходимо ввести имя текстового файла с числами.
